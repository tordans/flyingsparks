<p>Mark Norman Francis hat auf der <a href="http://thehighlandfling.com/2007/sessions/progressive-enhancement/">Highland-Fling-2007-Konferenz</a> darüber gesprochen, <strong>wie man mit JavaScript in der Webentwicklung umgehen sollte.</strong> Das Ideal: Die Website so konzipieren und umsetzen, dass sie auch ohne CSS, Ajax und JS funktioniert und dann mittels unobtrusive JavaScript einzelne Elemente <a href="http://de.wikipedia.org/wiki/Pimp#Verwendung_als_Verb">pimpen</a>.</p>
<p><a href="http://cackhanded.net/presentations/fling07">Die Präsentation gibt es online</a>: <a href="http://cackhanded.net/presentations/graded-browser-support-and-progressive-enhancement.pdf"><strong>The Highland Fling (pdf)</strong></a></p>
<p align="center"><img height="205" alt="zitat: unobstrusive javascript" hspace="2" src="/wp-content/uploads/unobstrusivejavascript.jpg" width="275" vspace="2" /> <img height="205" alt="zitat: unobstrusive javascript" hspace="2" src="/wp-content/uploads/unobstrusivejavascript-1.jpg" width="275" vspace="2" /></p>
<p>Eines der prägnanten Beispiele aus der Präsentation: Die <a href="http://uk.news.yahoo.com/">Featured-News-Box auf der britischen Yahoo-News-Seite</a> ist ohne JS ein Scrollbares Div. Mit JS bekommt es eine schöne vor-zurück-Funktionalität.</p>
