<p>Schon seit einer ganzen Weile, programmieren Leute aus dem <a href="http://www.mit.edu/">MIT</a> an einer Reihe an <a href="http://simile.mit.edu/">fancy Tools</a> -- alles voran <a href="http://simile.mit.edu/timeline/"><strong>Timeline</strong></a>, ein <q>"DHTML-based AJAXy widget for visualizing time-based events. It is like Google Maps for time-based information."</q> -- und erschreckt habe ich festgestellt, dass ich noch nirgends darüber gebloggt habe :).</p>
<p align="center"><a href="http://simile.mit.edu/timeline/"><img height="239" alt="timline simile" hspace="2" src="/wp-content/uploads/timeline.jpg" width="550" vspace="2" /></a></p>
<p>Für mein <a href="http://www.scoutpress.de">Diplomprojekt</a> hatte ich versucht, die Kalenderausgabe über einen 2. Kanal als Simile-Timeline darzustellen, bin aber leider an Zeichenkodierungsproblemen gescheitert...</p>
<p>Heute entdecke ich ein weiteres, sehr spanndendes JavaScript-Projekt der Simile-Familie: <a href="http://simile.mit.edu/timeplot/"><strong>Timeplot</strong></a> <q>"a DHTML-based AJAXy widget for plotting time series and overlay time-based events over them"</q>.</p>
<p align="center"><a href="http://simile.mit.edu/timeplot/"><img height="190" alt="timeplot" hspace="2" src="/wp-content/uploads/timeplot.jpg" width="550" vspace="2" /></a></p>
<p>Schade, dass man bisher so wenig Anwendungen dafür findet und Glückwunsch an die MITler, die mit dem GoogleMaps-API-artigen Ansatz so ein Randthema wie Zeit- und Datenvisualisierung so einfach gemacht haben.</p>
<p>Wäre es nicht beispielsweise einfach möglich, <del>die Postings eines Weblogs auf der Timeline darzustellen?</del> Das wäre noch cooler als entsprechende <a href="http://www.lalala.fr/blog/?p=25">bisherige Plugins</a>. Und parallel dazu den Traffik/Kommentare/... in einer Timeplot-Ansicht?<br />
<ins>Ich muss meine rhetorische Frage zur Timeline direkt selbst beantworten: Klar ist es möglich und es <a href="http://www.google.de/search?hl=de&amp;q=wordpress%20timeline%20plugin&amp;meta=">wurde auch schon gemacht</a>...</ins></p>
