<p>Gibt es hierfür etwa kein Plugin?</p>
<p>Ein WordPress-Plugin, das automatisch alle 2 Tage meine Delicious-Bookmarks inkl. Beschreibung in einer schönen Liste als Post veröffentlicht.</p>
<p>Natürlich hat der <a href="http://codex.wordpress.org/Plugins/Delicious">Codex einiges aufgelistet</a>, aber</p>
<ul>
<li><a href="http://autoblogger.sf.net/">Autoblogger</a> hat nur 50 Zeilen Code, ist kein Plugin und ich bekomme es auch so nicht ans Laufen.</li>
<li><a href="http://www.iconophobia.com/wordpress/?page_id=5">InlineRSS</a> hat kein automatisiertes Posten.</li>
<li><a href="http://nozell.com/blog/2005/01/30/updated-yet-another-daily-delicious-hack/">YetAnotherWeeklyDelicious</a> muss anscheinend serverseitig regelmäßig angepingt werden damit das Script ausgeführt wird?</li>
<li><a href="http://frenchfragfactory.net/ozh/archives/2004/10/05/tagalicious-a-way-to-integrate-delicious/">Taga.licio.us</a> erstellt auch nur eine Link-Liste aber hat kein automatisches Posten</li></ul>
<p>Ich hoffe, jemand hat einen Tipp!</p>
