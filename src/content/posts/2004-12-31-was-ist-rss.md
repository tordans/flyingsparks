<h3><a name="wofueristrssgut" class="jumper" id="wofueristrssgut"></a>Wofür ist RSS gut?</h3>

<p>RSS (RDF Site Summary) ermöglicht es Ihnen, automatisch informiert zu werden, wenn sich etwas an einer Seite verändert.</p>

<p>Sie können beispielsweise den so genannten <a href="index2.php?option=com_rss&amp;no_html=1" title="Der RSS-Feed dieser Internetseite.">RSS-Feed dieser Seiten</a> sowie auch <a href="http://www.rss-verzeichnis.de/">vieler anderer Seiten</a> abonnieren. Wird ein neuer Artikel veröffentlicht, bekommen Sie eine Zusammenfassung angezeigt.</p>

<h3><a name="wiefunktioniertrss" class="jumper" id="wiefunktioniertrss"></a>Wie funktioniert RSS?</h3>

<!--more-->

<p>Um diese Technik einzusetzen, benötigen Sie ein Programm, das RSS-Dateien lesen kann, einen so genannten RSS-Reader.</p>

<p>Ein kostenloser RSS-Reader ist beispielsweise <a href="http://www.rssbandit.org/" title="Zur Produktseite von RSS-Bandit" xml:lang="en" lang="en">RSS-Bandit</a>.</p>

<p>Auf der englischen Seite hebig.org gibt es eine <a href="http://www.hebig.org/blogs/archives/main/000877.php" title="Zu einer Liste von RSS-Readern" xml:lang="en" lang="en">sehr ausführliche Liste der verfügbaren RSS-Reader</a>.</p>

<h3><a name="warumsollteicheinenrssreadereinsetzen" class="jumper" id="warumsollteicheinenrssreadereinsetzen"></a>Warum sollte ich einen RSS-Reader einsetzen?</h3>

<ul>
  <li><span style="font-weight: bold;">Zeitersparnis</span> beim Lesen mehrerer News-Sites oder Weblogs</li>

  <li><span style="font-weight: bold;">Kostenersparnis</span>:
Insgesamt werden weniger Daten übertragen und nach der Aktualisierung
der RSS-Feeds können viele Meldungen auch offline gelesen werden.</li>

  <li>Immer mehr Websites bieten eine RSS-Datei (engl.: rss feed) an. Die meisten Weblogs und News-Seiten haben einen RSS-Feed (<a href="http://www.rss-verzeichnis.de/" title="Eine Liste von Internetseiten die bereits RSS-Dateien haben.">siehe RSS-Verzeichnis</a>).<br />

  <span style="font-weight: bold;">Je mehr Websites sie per RSS abbonieren desto mehr lohnt sich der Einsatz!</span></li>
</ul>
