Zu beobachten, wie Office 12 heranwächst, <a href="http://flyingsparks.wwwfiles.de/search/office12">bleibt </a>hoch interessant...

Der schon mehrmals erwähnte Jensen Harris weißt in einem neuen Beitrag auf <a href="http://blogs.msdn.com/jensenh/archive/2006/01/16/513313.aspx">Verbesserungen in Outlook</a> hin.

Der erste tolle Fund: Outlook wird endlich eine verbesserte Suche bekommen. Dann wird endlich der <a href="http://flyingsparks.wwwfiles.de/2005-10-17/volltextsuche-in-windows/">Umweg über Copernic</a> unnötig. Ich hoffe nur, dass Outlook dann auch endlich automatisch in seiner Archivdatei sucht!
Interessante Detail-Artikel in diesem Zusammenhang:
<ul>
	<li><a href="http://blogs.msdn.com/michael_affronti/archive/2005/12/12/502930.aspx">In welchem Interaktionsschritt wird zur Zeit die meiste Zeit verschwendet?</a></li>
	<li><a href="http://blogs.msdn.com/michael_affronti/archive/2005/12/19/505540.aspx">Wie wird das neue UI aussehen?</a></li>	<li><a href="http://blogs.msdn.com/willkennedy/archive/2005/12/16/504722.aspx">Wie sucht man eigentlich? (Auch UI)</a></li>
</ul>

Am Rande sei erwähnt, dass Outlook zukünftig eine native RSS-Unterstützung mitbringen wird: <a href="http://blogs.msdn.com/michael_affronti/archive/2005/12/22/506933.aspx">Artikel 1</a>, <a href="http://blogs.msdn.com/michael_affronti/archive/2006/01/03/508990.aspx">Artikel 2</a>. Ich bin gespannt, wie die bisher dafür bekannte Software <a href="http://newsgator.com/business.aspx">NewsGator</a> darauf reagiert...

Die zweite interessante Sache: Das Task-System von Outlook wird überarbeitet: Flags können Tasks sein, Tasks werden im Kalender und neben den Mails dargestelt, ... <a href="http://blogs.msdn.com/melissamacbeth/">Mehr im entsprechenden Blog</a>.


Microsofts Entscheidung, seinen Entwickeln die Erlaubnis zu geben, über ihre Arbeit zu Bloggen, war wirklich hervorragend. Dazu passt auch die Entscheidung, <a href="http://blogs.msdn.com/michael_affronti/archive/2005/12/15/504316.aspx">das Firefox-RSS-Logo für den IE und für Outlook zu übernehmen</a>. MS tut wirklich viel, sich ein offenes Image zu verpassen...
