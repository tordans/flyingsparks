<p>...und werden damit bald zum Quasistandard für Datenvisualisierungen auf einer Zeitachse werden.</p>
<p>Hier ein paar Beispiele, die IMO dazu führen, dass sich diese Visualisierungsmethode schnell verbreiten wird und damit hoffentlich "bald" davon ausgegangen werden kann, das Nutzer auch damit umzugehen wissen.</p>
<p>Prominentestes Beispiel: <strong>Google Finance</strong> und -- seit einer kurzen Weile -- die <strong>Google-Visualisation API</strong>, YouTube und viele andere Google-Dienste. -- <a href="http://fly.ingsparks.de/2008-04-06/visualisierungen-und-die-neue-api-von-google/">Mehr hierzu hier im Blog...</a></p>
<p align="center"><a href="http://fly.ingsparks.de/2008-04-06/visualisierungen-und-die-neue-api-von-google/"><img alt="" hspace="0" src="/wp-content/uploads/interactivetimeseries-1.jpg" align="baseline" border="0" /></a></p>
<p>Etwa zeitgleich aber visuell mit einem etwas anderer Ansatz kommt die <strong>Simile-Timeline</strong> daher um im Google-Maps-Stil via API Daten anzuzeigen. -- <a href="http://fly.ingsparks.de/2007-10-31/javascript-api-zur-datenvisualisierung-timeline-und-timeplot/">Auch hierzu mehr hier im Blog...</a></p>
<p align="center"><a href="http://fly.ingsparks.de/2007-10-31/javascript-api-zur-datenvisualisierung-timeline-und-timeplot/"><img alt="" hspace="0" src="/wp-content/uploads/timeline.jpg" align="baseline" border="0" /></a></p>
<p>Und jetzt kommen langsam die Adaptionen wie <a href="http://www.allofme.com/T/501006/LIFE">die <strong>Livestream-Timeline</strong></a> von AllOfMe (<a href="http://www.allofme.com/T/501006/LIFE">Beschreibung dieses Dienstes</a>).</p>
<p align="center"><a href="http://www.allofme.com/T/501006/LIFE"><img height="320" alt="allofme.com timeline" src="/wp-content/uploads/allofmecomtimeline.jpg" width="540" /></a></p>
<p><strong>Der wichtige Unterschied</strong> zwischen diesen Timelines und klassisches Zeitleisten, wie man sie aus MS Encarta und der Darstellung von Geschichtsdaten (<a href="http://www.pbs.org/empires/islam/flashtimeline.html">Beispiel</a>) kennt: <strong>Ein großer Ausschnitt wird Fokussiert und gleichzeitig der Context in einer kombinierten Anzeige+Auswahl angezeigt.</strong></p>
<p>Damit gehören diese Zeitleisten für mich in die Interface-Kategorie Fokus + Kontext (focus plus context) -- ein Themenfeld, zu dem es noch einige <strong>andere sehr interessante Interfacestudien</strong> gibt, zum Beispiel <br />
<a href="http://www.patrickbaudisch.com/projects/focuspluscontextscreens/">"focus-plus-context screens" (Karten auf Großscreens)</a> und <a href="http://www.patrickbaudisch.com/projects/halo/index.html">"halo" (PDA-Navigation)</a>, beide von Patrick Baudisch. Zu beiden gibt es auf der Seite Videos.</p>
<p>PS Offtopic: Jetzt hoffe ich nur noch, dass bald mal jemand für Wikipedia eine einfachere Timeline-Funktion entwickelt als die komplizierte (zwar sehr flexible) <a href="http://www.mediawiki.org/wiki/Extension:EasyTimeline">"Easy Timeline"</a>.</p>
